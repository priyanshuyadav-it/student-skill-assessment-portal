# Student Skill Assessment & Certification Portal

A third-year B.Sc. IT / BCA-level academic project built with:
HTML5, CSS3, JavaScript, PHP, MySQL, Bootstrap 5, XAMPP and Chart.js.

## Modules
- Student registration/login
- Student dashboard
- Skill categories
- MCQ assessments with timer
- Automatic score calculation
- Result history
- Skill-wise performance chart
- Certificate generation/printing
- Admin dashboard
- Admin question management
- Responsive Bootstrap UI

## XAMPP Setup
1. Copy the `student_skill_portal` folder to `C:/xampp/htdocs/`.
2. Start Apache and MySQL from XAMPP.
3. Open phpMyAdmin: `http://localhost/phpmyadmin`
4. Create/import the database using `database/student_skill_portal.sql`.
5. Open: `http://localhost/student_skill_portal/`
